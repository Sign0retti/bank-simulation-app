# 🏦 Bank Simulation App

A Spring Boot application that simulates basic banking operations.
This project was built **explicitly for training purposes** — focused on syntax practice,
best practices, design patterns, and project structuring with Java and Spring Boot.

---

## 🎯 Purpose

This is **not** a production-ready application.
The goal is to practice and consolidate knowledge in:

- REST API development with Spring Boot
- Entity modeling with JPA/Hibernate
- DTOs, Mappers, and separation of concerns
- Service layer with business rule validation
- Exception handling
- Environment variable management
- Docker and Docker Compose
- Project structure and best practices
